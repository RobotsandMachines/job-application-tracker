## Tool Used
Claude (Anthropic), used through the Claude app.

## How AI Was Used

### Planning
- Helped create an organized project plan from the assignment requirements.

### Setup & Troubleshooting
- Provided help fixing errors when creating the virtual environment and project structure.
- Helped fix a PowerShell execution policy error and an incorrect `requirements.txt`.
- Helped debug SQL errors (a comment missing a space after `--`, and a foreign key error from an invalid `job_id`).

### Database
- Helped improve some sections of the initial `schema.sql` from the assignment's schema.
- I chose to use a separate database (`job_tracker_project`) instead of altering my existing `job_tracker` database from the assignments, so earlier assignments keep working and the schema matches the requirements exactly. It helped fixing some design errors when I planned the database.
- It helped generate some random values for testing and filling the database tables for which I didn't have information.
- It helped debug errors during database creation.

### Code
- Helped me understand formatting errors on Flask routes, using Jinja templates and specific CSS features.
- I asked for line-by-line explanations of sample code generated by it to better understand how the works code instead of copying it.

### Design Changes I Made
- Although initially I was going to use Bootstrap for styling, I ended up choosing to use only CSS with variables, so I could control and learn the styling.
- Updated the layout multiple times to find the best way to fit everything on screen, but kept the code adaptable for different devices using CSS grids. 
- Made some late visual improvements like hovering effects, shadows, etc.
- Made several changes to the way inputs are handled for some of the tables, like Jobs having a limited selection of companies, and not just taking any text. 

## What I Verified Myself
I used AI fairly frequently for debugging since its one of the most time consuming tasks, but also took the time to test things myself. 
- Tested every CRUD operation, validation error and delete confirmation in the browser.
- Checked data and JSON columns directly in MySQL Workbench.
- Tested the Job Match results against the sample data.

## Reflection
Debugging, error fixing and optimizing redundant code were certainly the biggest and most relevant uses for AI in this project. It was a great time saver, mostly when debugging. But also form a learning perspective it really helped to get the code samples to understand how certain functions work, also some examples of how some functions where producing the wrong output as well as getting detailed explanations of every tingle tool I used. At some points the AI made mistakes, which I was able to luckily catch, but overall it was a very useful assistant.
